# SOP Loop 功能说明与使用手册

版本：0.3（执行闭环与行为分析版）
适用平台：macOS、Windows、Android  
数据位置：当前设备的 `localStorage` 与 IndexedDB

## 1. 产品定位

SOP Loop 是一个给个人使用的执行、学习和复盘工作台。它把重复流程、当天任务、专注记录、错题复习和每日复盘放在同一条数据链上：

```text
SOP → 任务计划 → 专注执行 → 学习结果 / 错题 → 每日复盘 → 下一版 SOP
```

它适合需要长期学习、备考、写作、编程或执行固定工作流程的人。软件默认离线工作，DeepSeek 只在用户主动点击 AI 整理时调用。

## 2. 已实现功能

### 2.1 今天

“今天”是启动后的默认页面，显示四个即时指标：

- 今日任务完成数 / 今日任务总数。
- 今日专注时长。
- 当前待复习错题数量。
- 每日复盘连续天数。

页面还会显示：

- 今日任务的前几项，可以直接勾选完成或开始专注。
- 逾期任务提醒。任务日期早于今天且今天没有完成时，会被标记为“逾期”。
- 待复习错题及其复习按钮。
- 已启用的 SOP，可以查看或直接开始。

### 2.2 任务计划

学习页的任务表单支持以下字段：

- 任务名称。
- 科目或知识路径。
- 计划分钟数，用来和真实专注时长比较。
- 计划日期。
- 优先级：高、中、低。
- 每日习惯开关。

任务分为两类：

1. 普通任务：只在计划日期进入当天计划；日期早于今天会进入逾期列表。
2. 每日习惯：不绑定日期，每天都出现在计划中，每天单独记录完成状态。

完成状态按日期保存。完成一个每日习惯不会把未来日期自动标记为完成；普通任务和旧版本数据也会自动兼容。

每条任务可以：

- 勾选或取消当天完成。
- 直接开始专注计时。
- 查看优先级和计划日期。
- 删除任务。

从 SOP 生成任务时，任务会自动继承 SOP 的预计分钟数和科目。这样同一条流程的计划、执行和偏差会被保存在同一条数据链上。

页面下方会列出最近的未来任务，方便提前安排下一天的学习内容。

### 2.3 专注计时

专注可以从任务或 SOP 直接开始，使用 25 分钟专注 + 5 分钟休息的番茄钟。计时期间会显示：

- 已经过的时间。
- 当前任务或 SOP 名称。
- 当前处于专注阶段还是休息阶段，以及剩余时间。
- 大圆环会随剩余时间推进，休息阶段使用独立颜色。
- 结束并记录按钮。

专注阶段自动结束后会进入 5 分钟休息，并生成一条 25 分钟专注记录；提前结束会按实际分钟记录。软件会在学习页要求补充本次执行结果、难度 / 阻力和下一步；可以跳过，之后仍能在记录中看到这次专注。若专注来自任务，该任务的番茄次数会增加。

专注记录会出现在学习页和分析页，作为后续复盘的事实数据。

### 2.4 SOP 管理

每个 SOP 包含：

- 名称。
- 一句话说明。
- 预计分钟数。
- 所属科目。
- 步骤列表。
- 是否出现在“今天”。
- 当前版本号。

保存 SOP 时不会覆盖掉历史内容。系统会先保存当前版本的快照，再把编辑结果保存为新版本，并保留最近 8 个版本。历史版本显示版本号、更新时间、预计时长和步骤数量，方便判断流程是不是越改越复杂。

从 SOP 可以一键生成今日任务，也可以直接开始一次 SOP 专注。

### 2.5 错题本

错题支持记录：

- 科目。
- 知识路径。
- 题型。
- 标题、题目和答案 / 解析。
- 标签。
- 题目图片或 PDF。
- 答案图片或 PDF。

错题列表可以按科目筛选，也可以搜索标题、题干、答案、标签、知识路径和题型。

#### 间隔复习

点击“记一次复习”后，系统会：

1. 增加复习次数。
2. 保存本次复习时间。
3. 按复习次数安排下一次复习间隔。
4. 生成一条错题复习记录，进入复盘数据。

默认间隔为：

```text
第 1 次：1 天
第 2 次：3 天
第 3 次：7 天
第 4 次：14 天
第 5 次及以后：30 天
```

错题卡片会显示下次复习日期。到期后重新出现在“今天”和错题页的待复习列表中。旧数据没有下次日期时，仍按 7 天规则兼容计算。

### 2.6 每日复盘

每日复盘只保留五个输入：

- 精力：1 到 5。
- 今天做得好的地方。
- 最大的阻碍。
- 阻碍分类：时间估计、任务拆分、环境干扰、精力状态、知识卡点或其他。
- 明天只改一件事。

页面同时显示当天的完成任务、专注时长和新增错题，减少手工回忆。

复盘保存后会保留在本地。点击“让 AI 整理”时，即使没有 API Key，也会使用本地规则生成事实、问题、明天动作和下周实验摘要。

如果配置了 DeepSeek 或其他 OpenAI Chat Completions 兼容接口，AI 会根据当天输入、专注结果、难度和最近 7 天洞察生成摘要。摘要会保存到当天复盘中，离开页面后仍能查看，不会因为重新渲染丢失。

### 2.7 分析与周报

分析页提供最近 7 天的专注柱状图，并把执行、任务、错题和复盘放到同一个时间窗口中比较。

当前分析面板包括：

- **可行动洞察**：识别 SOP 预计时长偏差、科目专注与错题集中、精力与专注的差异、重复阻碍。
- **SOP 表现**：每条 SOP 的执行次数、平均实际分钟、预计分钟、偏差百分比和关联任务完成率。
- **科目表现**：各科目专注时长、专注次数、完成任务数、新增错题数和错题复习次数。
- **精力与专注**：按每日复盘的 1–5 精力分组，比较平均专注时长和任务完成数。
- **阻碍分类**：统计阻碍类型出现次数，并保留最近的原文例子。
- **计划与实际**：列出计划分钟和关联专注分钟，优先显示偏差最大的任务。
- **专注难度**：按 1–5 难度比较专注次数、平均时长和结果记录率，发现“难但没有留下结果”的执行段。

学习结果区域显示：

- 最近 7 天完成的任务。
- 当前逾期任务。
- 错题总数。
- 错题复习次数。

点击“生成周报”会生成一份 Markdown 文本，包含：

- 本周专注总时长。
- 完成任务数。
- 复盘次数。
- 错题总数。
- 最近记录的阻碍。
- SOP 表现和计划 / 实际偏差。
- 阻碍分类与精力差异。
- 下周只做一个 SOP 改动的实验建议。

周报可以复制到笔记软件或作为下一周的计划起点。

### 2.8 数据和模型设置

设置页支持：

- 配置接口地址。
- 配置模型名称。
- 保存 API Key。
- 导出 JSON 备份。
- 导入 SOP Loop、virtual-study-room、mistake-notebook 的 JSON 数据。
- 清空当前设备数据。

默认接口配置为：

```text
接口地址：https://api.deepseek.com/chat/completions
模型：deepseek-chat
```

接口只在用户主动使用 AI 功能时请求。没有 API Key 时不会产生网络请求。

### 2.9 操作指引

首次打开时会出现一组简短的操作指引。它采用“当前按键高亮 + 说明卡片 + 下一步”的方式，依次介绍：

1. 进入学习工作台。
2. 添加任务并填写计划分钟。
3. 从任务开始专注并在结束后记录结果。
4. 打开每日复盘。
5. 查看分析和生成周报。

指引会在跨页面时自动切换到对应页面，用户可以选择“上一步”“下一步”或“跳过”。勾选“不再显示操作指引”后，偏好会保存在本机；之后仍可以在“设置 → 操作指引”中手动重新打开。按 `Esc` 也可以关闭当前指引。

## 3. 数据模型

当前工作区数据版本为 `3`，主要实体如下（新增字段均向后兼容）：

```text
Workspace
├─ sops[]
│  ├─ id / title / description / estimate
│  ├─ steps[] / subject / active
│  ├─ version / history[]
│  └─ createdAt / updatedAt
├─ tasks[]
│  ├─ title / date / kind / priority / plannedMinutes
│  ├─ completedOn[] / completedPomodoros
│  ├─ subject / categoryPath / sopId
│  └─ createdAt / updatedAt
├─ focusSessions[]
│  ├─ duration / taskId / sopId / sessionName
│  └─ result / difficulty / nextAction
├─ reviews[]
│  ├─ energy / good / block / blockerCategory
│  └─ next / aiSummary
├─ mistakes[]
│  ├─ question / answer / knowledgePath / tags
│  ├─ reviewCount / reviewInterval
│  ├─ lastReviewedAt / nextReviewAt
│  └─ attachmentIds[] / answerAttachmentIds[]
├─ subjectConfig
├─ settings
│  └─ 操作指引偏好保存在本机 localStorage
└─ sync
```

### 任务完成日期

`completedOn` 是日期数组，例如：

```json
["2026-10-24", "2026-10-25"]
```

这样每日习惯可以每天单独统计，旧版本只有 `completed: true` 的任务会按任务日期自动迁移。

### SOP 历史版本

`history` 保存编辑前的快照，不保存执行记录。执行记录仍然放在 `focusSessions` 中，所以可以分别回答：

- 这个流程现在是什么样。
- 这个流程以前是什么样。
- 每一次执行用了多少时间。

### 计划、执行和结果的关联

一条任务可以关联一个 SOP，并记录 `plannedMinutes`。从任务开始的专注会保存 `taskId`，结束后的结果会保存到同一条 `focusSessions` 记录。分析页据此计算：

```text
任务计划分钟 → 关联专注实际分钟 → 专注结果 / 难度 / 下一步 → 每日复盘阻碍 → 下一版 SOP
```

如果任务没有关联 SOP，系统仍会按任务和科目统计，不会丢失专注数据。

## 4. 推荐使用流程

### 早上：安排

1. 打开“学习”。
2. 添加今天最重要的 1 到 3 个任务。
3. 给任务设定日期、优先级和计划分钟数。
4. 需要每天重复的内容勾选“每日习惯”。
5. 需要固定执行的内容，从 SOP 生成任务。

### 中间：执行

1. 点击任务或 SOP 的“开始”。
2. 完成一个可交付的小结果。
3. 点击“结束并记录”，补充结果、难度和下一步。
4. 必要时把执行中出现的问题记到错题或每日复盘。

### 晚上：收口

1. 打开“每日复盘”。
2. 填写精力、做得好的地方、阻碍和明天的一个改动。
3. 点击“让 AI 整理”，保存结构化摘要。
4. 对当天新增错题点击“记一次复习”，让系统安排下一次日期。

### 每周：改进

1. 在“分析”查看最近 7 天的实际专注时间。
2. 生成周报，观察 SOP 偏差、科目错题和重复阻碍。
3. 在 SOP 页面修改一个最小步骤。
4. 下一周观察新版本是否降低了时长偏差或重复阻碍。

## 5. 本地存储和隐私

- 普通数据保存在设备 `localStorage`。
- 图片和 PDF 附件保存在设备 IndexedDB。
- 默认不上传任务、错题和复盘。
- 使用 AI 时，当前复盘输入和统计事实会发送到设置中的接口。
- API Key 当前保存在本地工作区配置中，适合个人本机使用；如果要把设备交给别人，应先清空或删除 Key。
- JSON 备份包含附件 ID，不包含 IndexedDB 中的附件本体。换设备前需要重新添加附件，或后续使用完整备份功能。

## 8. 当前边界和下一步

这一版已经可以完整支持手动计划、执行、错题间隔复习和每日复盘，但以下能力还没有加入：

1. macOS / Windows 应用活动时长采集。
2. 系统通知和定时复盘提醒。
3. 多设备同步与冲突合并。
4. 包含 IndexedDB 附件本体的完整备份。
5. SOP 执行中的逐步骤勾选和执行偏差记录。
6. 可确认、可追溯的 AI 洞察卡片。
7. 日历视图和按周拖拽排程。

下一轮最值得做的是系统提醒、附件完整备份和 SOP 逐步骤执行记录。这三项会直接减少遗漏，也能让后续行为分析有更细的证据。
